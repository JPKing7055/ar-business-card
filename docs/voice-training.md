# 用 GPT-SoVITS 做出自己的聲音

目標：在自己的電腦上訓練 GPT-SoVITS，再用 `tools/synth_faq.py` 把 `faq.json` 的字幕一次合成成本人的聲音。

> 電腦需求：NVIDIA 顯卡。推論（合成）約 4GB 顯示記憶體就夠；訓練一般建議 6GB 以上，6GB 剛好在下限，訓練時把 batch size 調小。
> WebUI 的按鈕名稱會隨版本略有不同，以實際畫面為準。

## 1. 安裝

1. 到 GPT-SoVITS 的 Windows 整合包頁面（Hugging Face：`lj1995/GPT-SoVITS-windows-package`，或 GitHub Releases）下載最新的 v2Pro 整合包（7z，約 8GB）。50 系列顯卡請選檔名有 `nvidia50` 的版本。
2. 解壓縮到**路徑沒有中文、沒有空格**的資料夾，例如 `E:\AI\GPT-SoVITS`。
3. 執行 `go-webui.bat`，瀏覽器會打開 WebUI。

整合包內建 Python 和所有套件，不需要另外安裝，也不要用這個專案的 `.venv`。

## 2. 錄製訓練用的錄音

- **長度**：至少 1 分鐘，建議 3～5 分鐘。越多越穩定，但品質比長度重要。
- **環境**：安靜的房間，關掉風扇、冷氣；手機或麥克風固定距離（約一個拳頭到 20 公分）。
- **語氣**：用你平常說話、自我介紹的語氣，不要刻意播音腔。訓練出來的聲音會很像你錄音時的狀態。
- **格式**：WAV 最好，m4a 也可以。可以一句一個檔，也可以錄成一整段（WebUI 會自動切）。
- **內容**：照下面的錄音稿念。前半段是一般句子（涵蓋各種發音），後半段是 `faq.json` 的回答，讓模型熟悉這些用詞。

## 3. 訓練（WebUI）

### 3-1 準備資料（「前置數據集獲取工具」分頁）

1. **語音切分**：輸入錄音資料夾，輸出到例如 `output/slicer_opt`。一段太長的錄音會切成幾秒到十幾秒的片段。
2. **語音降噪**（選用）：錄音環境很安靜可以跳過，降噪有時反而讓聲音變悶。
3. **語音辨識（ASR）**：中文選內建的中文模型，產生每個片段的逐字稿（`.list` 檔）。
4. **校對逐字稿**：打開校對工具，逐句聽、修正辨識錯的字。**這步最重要**，逐字稿錯了，模型會學錯發音。

### 3-2 格式化與微調（「GPT-SoVITS-TTS」分頁）

1. 輸入一個實驗名稱，例如 `bernie`，版本選 v2Pro。
2. **訓練集格式化**：選好上一步的 `.list` 檔和切分後的音檔資料夾，一鍵執行。
3. **SoVITS 訓練**：batch size 設 2～4（6GB 顯示記憶體從 2 開始試），其他用預設值。
4. **GPT 訓練**：batch size 同樣設 2～4，其他用預設值。
5. 訓練中如果出現 `CUDA out of memory`，把 batch size 再調小，並關掉其他使用顯示卡的程式（例如生圖工具、遊戲）。

### 3-3 試聽

在「推理」分頁選剛訓練好的 GPT 和 SoVITS 模型，開啟推理 WebUI：

- **參考音頻**：從切好的片段挑一段 3～10 秒、咬字清楚、語氣自然的，填上它**一字不差**的逐字稿。
- 輸入幾句 `faq.json` 的字幕試聽，滿意後記下：
  - 參考音頻的路徑與逐字稿（之後合成都用同一段，聲音才一致）
  - 訓練好的模型檔位置：`GPT_weights_v2Pro/` 與 `SoVITS_weights_v2Pro/` 底下的檔案

## 4. 批次合成 FAQ 語音

### 4-1 啟動 GPT-SoVITS API

編輯 GPT-SoVITS 資料夾裡的 `GPT_SoVITS/configs/tts_infer.yaml`，在 `custom:` 區段把模型路徑改成你訓練好的檔案：

```yaml
custom:
  device: cuda
  is_half: true
  version: v2Pro
  t2s_weights_path: GPT_weights_v2Pro/bernie-e15.ckpt      # 換成你的 GPT 模型
  vits_weights_path: SoVITS_weights_v2Pro/bernie_e8_s200.pth  # 換成你的 SoVITS 模型
  # 其他欄位保持原樣
```

在 GPT-SoVITS 資料夾開 PowerShell，用整合包內建的 Python 啟動 API：

```powershell
runtime\python.exe api_v2.py -a 127.0.0.1 -p 9880 -c GPT_SoVITS/configs/tts_infer.yaml
```

看到伺服器啟動的訊息後，**這個視窗保持開著**。

### 4-2 執行合成

另開一個 PowerShell，到這個專案：

```powershell
cd E:\AIProjects\ar-business-card
.venv\Scripts\Activate.ps1
git pull

# 先看會處理哪些題目
python tools/synth_faq.py --ref "E:/AI/GPT-SoVITS/output/slicer_opt/某一段.wav" --ref-text "參考音頻的逐字稿" --dry-run

# 正式合成
python tools/synth_faq.py --ref "E:/AI/GPT-SoVITS/output/slicer_opt/某一段.wav" --ref-text "參考音頻的逐字稿"
```

腳本會：

- 只處理還沒有音檔的題目；第一題用的是本人真實錄音，不會被覆蓋。
- 每題合成後自動裁空白、標準化音量、算嘴型曲線，存到 `audio/faq/`，並寫回 `faq.json`。
- 某一題不滿意：`--ids skills --overwrite` 只重做那一題；語速可以用 `--speed 0.95` 調整。

### 4-3 確認後上傳

1. 先在電腦上聽 `audio/faq/` 的每個音檔。
2. 滿意後只 commit 這兩樣：

```powershell
git add faq.json audio/faq
git commit -m "FAQ 語音：GPT-SoVITS 合成"
git push
```

## 常見問題

- **連不到 API**：確認 4-1 的視窗還開著、沒有錯誤訊息，網址是 `http://127.0.0.1:9880`。
- **某些字念錯**：GPT-SoVITS 的中文發音處理以簡體中文資料為主，繁體字大多沒問題，少數破音字或繁簡寫法差異較大的字可能念錯。可以把那一題的字幕換個說法，或在 `faq.json` 暫時改成簡體字合成後再改回來（字幕顯示和合成用的是同一段文字，改回繁體後不需重新合成）。
- **聲音不像或不穩定**：換一段參考音頻；或增加訓練錄音、重新校對逐字稿後再訓練。
- **語氣太平**：參考音頻的語氣會直接影響輸出，挑一段比較有精神的。
